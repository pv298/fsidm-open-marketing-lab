# FSIDM Open Marketing Lab

A practical, beginner-friendly collection of digital marketing, SEO, AI and automation resources maintained by FSIDM.

## What's inside
- SEO audit starter: a browser-based manual review checklist.
- SEO resources: technical, on-page and local SEO checklists.
- AI prompt library: prompts for research, content planning and marketing workflows.
- Automation blueprints: practical workflow ideas for tools such as Make.com.
- Student projects: guided exercises based on realistic business scenarios.

## Quick start
Open `tools/seo-audit/index.html` in a browser. No installation is required.

## Project structure
```
docs/seo/                  SEO checklists
docs/automation/           Automation blueprints
prompts/                   Reusable AI prompts
projects/                  Student project ideas
tools/seo-audit/           Browser-based SEO review checklist
```

## Important
The SEO checklist is a manual review aid, not a crawler. It does not fetch, scan or automatically score a live website.
