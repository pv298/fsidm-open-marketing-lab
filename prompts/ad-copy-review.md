# Prompt: review advertising copy

Review the supplied ad copy for clarity, relevance and policy risk.

## Inputs
- Platform:
- Product/service:
- Target audience:
- Geography:
- Offer and verified terms:
- Landing page:
- Draft primary text/headline/description:

## Review
1. Identify unclear or unsupported claims.
2. Check whether the message matches the landing page.
3. Improve the hook without using misleading urgency.
4. Provide 3 concise headline alternatives.
5. Provide 2 primary text alternatives.
6. Suggest one clear CTA.
7. Flag claims that need evidence or legal/platform review.

Never invent discounts, guarantees, results, testimonials or scarcity.
