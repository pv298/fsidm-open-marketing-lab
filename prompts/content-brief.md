# Prompt: create a useful content brief

You are a content strategist. Build a practical brief using only the information supplied.

## Inputs
- Business:
- Audience:
- Offer:
- Primary topic:
- Search intent:
- Location (if relevant):
- Brand voice:
- Evidence/source material:
- Desired action:

## Prompt
Create a content brief with:
1. Audience problem and intent
2. One-sentence content promise
3. Suggested title options
4. H1 and logical H2/H3 outline
5. Questions the content must answer
6. Evidence and first-hand experience needed
7. Internal-link opportunities (mark as suggestions, not verified URLs)
8. CTA aligned with intent
9. Accuracy and originality checks

Do not invent statistics, testimonials, rankings, product features or sources. Flag missing information as questions.
