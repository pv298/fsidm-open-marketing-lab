## Development standard for every module

Each module resource should include:
1. Exact brochure module title and number.
2. Learning objectives.
3. Concepts and step-by-step explanation.
4. Tools/platforms (clearly distinguish brochure-listed tools from optional additions).
5. Practical task and realistic brief.
6. Expected student deliverable.
7. Review checklist / assessment rubric.
8. Ethical, privacy, platform-policy and accuracy notes where relevant.
9. Further reading or official documentation links, verified when added.

## Brochure references and boundaries

- The brochure lists the curriculum above and separately says students will learn/work with 50+ industry-leading tools.
- The brochure does not provide detailed lesson plans, duration per module, assessment rubrics, or a complete named list of all 50+ tools in the extracted curriculum pages. Those must not be invented or presented as brochure facts.
- Use current official product documentation when writing tool-specific instructions, and note the date checked.
