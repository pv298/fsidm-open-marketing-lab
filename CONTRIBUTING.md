# Contributing

Thanks for helping improve the FSIDM Open Marketing Lab.

## Good contributions
- Fix unclear or incorrect instructions.
- Add practical examples based on realistic marketing scenarios.
- Improve checklists while keeping them beginner-friendly.
- Add prompts with clear inputs, expected outputs and limitations.
- Add student exercises that can be completed without paid tools.

## Before submitting
1. Explain the problem your change solves.
2. Keep advice actionable and verifiable.
3. Never publish client data, personal information, passwords, API keys or confidential campaign details.
4. Avoid unsupported promises such as guaranteed rankings, leads or jobs.
5. Mention tool versions where relevant.

## Pull requests
Use a clear title and describe what changed, why it matters, and how you tested it.
