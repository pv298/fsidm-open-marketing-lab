# Student project ideas

These are learning exercises. Use demo data or obtain written permission before working with real client accounts.

1. Local SEO audit: review a sample local business website/profile using the local SEO checklist.
2. Content strategy: cluster a supplied keyword set and create a 4-week content plan.
3. Lead funnel review: map a landing page, form, CRM stage and follow-up process.
4. Campaign reporting: build a report from a synthetic dataset and explain lead quality.
5. Automation prototype: create a lead acknowledgement and task workflow using dummy contacts.

For each project, submit the brief, assumptions, evidence, deliverable, limitations and a short reflection.
