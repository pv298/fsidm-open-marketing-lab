# On-page SEO checklist

Use this checklist page by page. Record evidence and prioritize fixes by impact and effort.

## Search intent and content
- [ ] The page has one clear primary search intent.
- [ ] The title accurately describes the page and includes the primary topic naturally.
- [ ] The H1 clearly communicates the page topic.
- [ ] Headings create a logical content hierarchy.
- [ ] The page answers the visitor's likely questions.
- [ ] Content is original, useful, current and specific.
- [ ] Claims and statistics have appropriate sources where needed.

## Metadata and URLs
- [ ] Title tag is unique and descriptive.
- [ ] Meta description is unique and encourages a relevant click.
- [ ] URL is readable, concise and stable.
- [ ] Canonical URL is correct.
- [ ] Indexing directives are intentional.

## Images and links
- [ ] Images are relevant and compressed appropriately.
- [ ] Informative images have meaningful alt text; decorative images use empty alt text.
- [ ] Internal links use descriptive anchor text.
- [ ] Broken links and unnecessary redirects are checked.
- [ ] Important pages are reachable through internal links.

## Conversion and experience
- [ ] The next step is clear.
- [ ] Calls to action match the page intent.
- [ ] Mobile layout is usable.
- [ ] Contact and trust information is easy to find.
