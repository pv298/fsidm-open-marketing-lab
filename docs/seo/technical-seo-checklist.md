# Technical SEO checklist

This is a review checklist, not an automated crawler.

## Crawlability and indexability
- [ ] Important URLs return the expected HTTP status.
- [ ] Robots.txt does not unintentionally block important resources or pages.
- [ ] XML sitemap includes canonical, indexable URLs.
- [ ] Noindex directives are intentional.
- [ ] Redirect chains and loops are absent.
- [ ] Canonical tags point to the preferred URL.

## Site architecture
- [ ] Important pages are reachable within a sensible click depth.
- [ ] Internal links use crawlable anchors.
- [ ] Pagination and faceted navigation are handled intentionally.
- [ ] Duplicate URL variants are consolidated where appropriate.

## Performance and mobile
- [ ] Core Web Vitals are reviewed using field data where available.
- [ ] Images are appropriately sized and modern formats are considered.
- [ ] JavaScript does not hide essential content from users or search engines.
- [ ] Mobile usability is checked on representative templates.

## Structured data and security
- [ ] Structured data matches visible page content.
- [ ] Markup is validated with an appropriate testing tool.
- [ ] HTTPS is enforced and mixed content is resolved.
- [ ] Important templates are checked after deployments.

## Reporting
Record affected URL/template, evidence, user impact, SEO impact, recommended fix, owner and priority.
